## 统一产品介绍

推荐统一描述：

`Resume Navigator` 是一个面向中文求职场景的简历诊断工具。  
它不只给你一个分数，而是先告诉你：

- 这份简历现在到底能不能投
- 为什么能投，或者为什么还不能投
- 投递前最该先补什么
- 面试大概率会追问哪里

它的重点不是把简历写得更花，而是把简历改成更像招聘方真正想看到的材料。

---

## 平台共用卖点

每个平台的文案都优先围绕这 6 个点展开：

1. 不是只看关键词，而是看 `JD 要求 -> 简历证据 -> 缺口 -> 下一步动作`
2. 不是只给分，而是先给“能不能投”的判断
3. 不是只停在诊断，而是继续给改写建议和面试承接
4. 不是乱编经历，而是要求真实证据
5. 默认简体中文，适合中文求职者直接使用
6. 隐私优先，真实简历默认不公开上传

### 正文模板

很多简历问题，不是“没有经历”，而是“经历没有写成能被招聘方信服的证据”。

我最近做了一个简历诊断工具 `Resume Navigator`，它和普通简历打分器不太一样：

1. 先告诉你这份简历现在能不能投
2. 再拆开讲为什么
3. 再告诉你先补哪一块最值钱
4. 最后还会接到更像真实面试的追问

它不是只扫关键词，也不是让 AI 帮你乱编经历。  
重点是把 `JD 要求` 和 `简历里的真实证据` 一条条对上。

如果你也经常遇到这些情况：

- 海投很多但回复率低
- 觉得自己经历相关，但简历总是写不出来
- 面试总被追问“你这个到底做过多深”

这个工具可能会有帮助。

GitHub / 试用页我放在评论区或主页。
