# Resume Navigator v0.5.0

这次版本的目标，是把它从“开发中的工具原型”推进到“求职者可以直接试用的最终版雏形”。

## 这次更新了什么

- 首页更像产品入口，不再是开发者说明页
- 结果页去掉开发者视角信息，改成用户最关心的结论顺序
- 新增公开示例案例页，可直接理解典型问题长什么样
- 新增可复制的投递摘要与面试练习卡
- 新增更完整的 JD 改写建议卡片
- 面试承接升级为“为什么会被问 + 怎么答 + 最容易答偏的点”
- 后台任务页不再暴露阶段耗时等开发者细节
- 公开资料补充增强了查询组合和来源结构说明
- 历史记录和反馈页改成 owner-only，减少最终产品中的后台暴露

## 这一版更适合谁

- 已经有目标 JD，准备正式投递的人
- 觉得自己经历相关，但简历总写不出“证明感”的人
- 面试总被追问“你这个到底做过多深”的人

## 仍然坚持的产品原则

- 不让模型直接替代总分判断
- 不让产品鼓励用户编造经历
- 公开资料只做补充层，不直接覆盖确定性结论
- 默认隐私优先，真实简历不公开上传
